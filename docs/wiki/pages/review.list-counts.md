# Die Zahlen an den Arbeitslisten lesen

Unterscheide die Größe einer Arbeitsliste von den gerade sichtbaren Treffern.

Die Zahl neben einer Arbeitsliste sagt dir, wie viele Dialoge dort eingeordnet sind. Die vier Listen teilen den Bestand auf; „Alle“ nennt die Gesamtzahl. Hast du eine Suche, einen Statusfilter oder eine Fehlerkategorie gesetzt, siehst du innerhalb der gewählten Liste nur die dazu passenden Treffer. Deshalb können weniger Dialoge erscheinen, als die Listenzahl vermuten lässt.

Wie die Einordnung zustande kommt und weshalb ein bestätigter Dialog noch unter „Offen“ stehen kann, erklärt [„Review-Statuszeichen und Arbeitslisten“](review.status-signs.md).

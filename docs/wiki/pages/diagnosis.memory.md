# Wenn der Arbeitsspeicher knapp wird

Wenn die Modelle nicht genug Arbeitsspeicher bekommen, lohnt sich zuerst ein Blick auf die übrigen laufenden Programme.

Die Sprachverarbeitung braucht RAM, den Arbeitsspeicher deines Macs. Ist er knapp, schließe zunächst andere speicherintensive Programme. Falls der Patch noch reagiert, verwende vorher „Anhalten“ und warte auf die sichere Pause, damit aktive Schritte gespeichert werden.

Fordert die Konsole einen Neustart an, folge diesem Hinweis und öffne danach wieder denselben Arbeitsordner. Freier Platz auf dem Systemlaufwerk hilft macOS bei der Speicherverwaltung. Auf einem Mac mit 8 GB kann die automatische Textprüfung erst nach der Spracherzeugung beginnen; solange diese Prüfung weiterarbeitet, gehört das Warten zum [normalen Ablauf](launcher.low-ram.md).

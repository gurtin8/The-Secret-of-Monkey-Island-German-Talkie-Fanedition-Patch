# Fortschritt und Speicherhinweise verstehen

Verfolge einen laufenden Auftrag und ordne Hinweise auf knappen Arbeitsspeicher ein.

Wenn ein Auftrag läuft, zeigt dir der Status die aktuelle Phase, den bearbeiteten Dialog und die Zahl der bereits erledigten Dialoge. Ein einzelner Erzeugungs- oder Prüfschritt kann länger dauern. Schau zunächst auf diese Angaben, bevor du einen weiteren Start versuchst.

Der Speicherhinweis schätzt, ob für das Modell genug Arbeitsspeicher frei ist. Wird es knapp, kann die Erzeugung langsamer werden oder abbrechen. Für die weitere Fehlersuche ist dann die konkrete [Meldung](review.messages.md) entscheidend; die Speicherschätzung allein erklärt einen Abbruch noch nicht.

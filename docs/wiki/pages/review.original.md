# Den Originalton verwenden

Behalte für einen Dialog die vorhandene Originalaufnahme.

Möchtest du für einen Dialog die vorhandene Originalaufnahme verwenden, wähle unter „Ausgabe“ die Option „Originalton verwenden“ und [verarbeite den Dialog](review.batch.md). Der Patch kopiert die geprüfte Originalaufnahme. Dafür braucht er weder ein Sprachmodell noch einen [Seed](review.seed.md).

Wird daneben eine frühere deutsche Ausgabe angezeigt, kannst du sie weiterhin zum Vergleich anhören. Ihre alten Prüfergebnisse gehören zu dieser deutschen Fassung; sie bewerten nicht den nun gewählten Originalton.

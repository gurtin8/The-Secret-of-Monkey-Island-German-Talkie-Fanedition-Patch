# Ein vorhandener Patch läuft bereits

Der Hinweis erscheint, wenn der zu deinem Projekt gehörende Patch im Hintergrund noch läuft.

Dieser Hintergrunddienst wird im Dialog als Projektserver bezeichnet. Wenn gerade kein Auftrag läuft, kannst du „Server stoppen und neu starten“ wählen und mit dem aktuellen Patch weiterarbeiten. Deine Arbeitsdaten bleiben dabei erhalten.

Mit „Abbrechen“ lässt du den vorhandenen Dienst weiterlaufen. Solange er aktiv an einem Auftrag arbeitet, ist der Neustart gesperrt.

<details>
<summary>Meldungen zu diesem Thema nachschlagen</summary>

- Ein eigener Launcher-Server läuft bereits
- Server stoppen und neu starten
- Neustart abgebrochen; bestehender Server läuft weiter.
- Eigener Launcher läuft bereits auf Port
- Ein eigener Patch-Server läuft bereits
- Eigener Patch läuft bereits auf Port

</details>

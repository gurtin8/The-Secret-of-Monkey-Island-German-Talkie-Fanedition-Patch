# Downloads starten

Sind Pfade und Bestätigungen vollständig, kann die Einrichtung beginnen.

Klicke auf „Downloads starten“. Der Patch richtet zuerst Python ein und lädt danach im selben Fenster die übrigen Pakete und Modelle. In der Konsole unten kannst du verfolgen, wie weit er mit Laden und Einrichten ist.

Sollte die Verbindung abbrechen, behalte denselben Arbeitsordner bei. So kann der Patch bereits geprüfte Dateien beim nächsten Start weiterverwenden, statt alles erneut herunterzuladen.

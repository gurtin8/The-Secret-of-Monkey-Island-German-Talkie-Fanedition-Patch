# Änderungen speichern

Text, Notizen und Einstellungen werden automatisch gespeichert.

Bevor du die Review verlässt, achte auf „Gespeichert“. Steht dort „Wird gespeichert …“, wartet der Patch noch auf die Bestätigung. Auch vor einer [Vorschau](review.audition.md), der [Verarbeitung ausgewählter Dialoge](review.batch.md) und einem Dateiexport wartet er auf offene Speicherungen. Scheitert das Speichern, startet der davon abhängige Auftrag nicht.

Bei „Speicherfehler“ bleibt deine Eingabe im Editor erhalten. Lies die Meldung und bearbeite das betroffene Feld erneut, um einen weiteren Speicherversuch auszulösen. Sobald die Änderung gespeichert ist, steht sie für den nächsten Versuch bereit. Eine neue Aufnahme entsteht erst durch die Verarbeitung; eine Vorschau wählst du anschließend selbst aus.

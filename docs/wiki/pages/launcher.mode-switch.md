# Eine Fassung fortsetzen oder eine weitere erstellen

Moduswahl und Fassungswahl werden erst durch deinen ausdrücklichen Start wirksam.

Bei einer unfertigen Fassung erzeugt „Rendering starten“ die noch fehlenden Aufnahmen mit der gewählten Einstellung. Ist sie in dem laufenden Patch pausiert, wird derselbe Auftrag fortgesetzt; bei geändertem Modus wartet der Patch zuvor einen sicheren Arbeitsschritt ab. Bereits gültige fertige Aufnahmen bleiben erhalten. Innerhalb der Fassung können dadurch verschiedene Methoden zusammenkommen.

Eine fertige Fassung beginnt durch einen Klick auf „Rendering starten“ keinen neuen Durchlauf. Im Dialog wählst du „Weitere Fassung erstellen“, „Ausgewählte Fassung ersetzen“ oder „Abbrechen“. Eine weitere Fassung besitzt eigene Aufnahmen und ihre eigene Review.

Beim Ersetzen bleiben die bisherige Fassung und ihre Review erhalten, bis die neue vollständig fertig ist. Bei Fehler oder Abbruch kannst du weiterhin auf die alte Fassung zugreifen. Erst der erfolgreiche Abschluss ersetzt sie in der Auswahl.

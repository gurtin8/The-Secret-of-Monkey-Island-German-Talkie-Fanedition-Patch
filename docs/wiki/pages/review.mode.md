# Deutsche Stimme oder Originalton wählen

Lege fest, welche Art von Aufnahme der nächste Verarbeitungslauf verwenden soll.

Soll die nächste Verarbeitung eine neue deutsche Stimme erzeugen, wähle unter „Ausgabe“ die Option „Deutsch“. Möchtest du stattdessen die vorhandene Originalaufnahme einsetzen, wähle „Originalton verwenden“. Damit merkst du die gewünschte Änderung vor; wirksam wird sie erst, wenn du den Dialog [verarbeitest](review.batch.md).

Die Originalaufnahme lässt sich nur wählen, wenn der Patch sie erfolgreich prüfen konnte. Zum Übernehmen dieses Tons braucht er kein Sprachmodell. Den genauen Ablauf erklärt [„Den Originalton verwenden“](review.original.md).

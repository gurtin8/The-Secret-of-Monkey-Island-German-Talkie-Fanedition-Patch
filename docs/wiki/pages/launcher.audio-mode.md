# Wie der Patch die Spielbasis vorbereitet

Der Patch bereitet die Audiodaten für die Ultimate Talkie Edition direkt auf macOS auf.

Aus der PC-Special-Edition bereitet der Patch die Ultimate Talkie Edition (UTE) als Grundlage deiner Sprachfassung vor.

Für die Audioarbeit verwendet der Patch native Werkzeuge auf dem Mac. Der deutsche Patch läuft anschließend mit [Wine](launcher.wine.md).

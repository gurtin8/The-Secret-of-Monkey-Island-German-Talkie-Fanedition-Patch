# Ausgewählte Dialoge verarbeiten

Verarbeite einen Dialog oder mehrere markierte Dialoge in einem Lauf.

Markiere die gewünschten Dialoge mit dem Kästchen im Dialogkopf. Für eine größere Auswahl nutzt du „Alle Treffer auswählen“: Das erfasst sämtliche gefilterten Treffer, auch auf anderen Seiten. Mit „Auswahl löschen“ hebst du die Markierungen wieder auf. Wenn die Auswahl passt, starte „Ausgewählte Dialoge verarbeiten“. Der Patch speichert vorher offene Text- und Einstellungsänderungen.

Bei einem einzelnen Dialog verarbeitet der Patch die gewählte Ausgabeart. Bei mehreren berücksichtigt er Dialoge mit einem offenen Auftrag sowie Dialoge mit einer [passenden angenommenen Probe](review.probe.md). Einträge, auf die beides nicht zutrifft, überspringt er. Eine passende Probe wird wiederverwendet, statt sie erneut zu erzeugen.

Der „Rendermodus für die Auswahl“ bestimmt die gemeinsame [Rechenmethode](review.backend.md). Hast du direkt an einem Dialog etwas anderes gewählt, gilt dort diese eigene Wahl.

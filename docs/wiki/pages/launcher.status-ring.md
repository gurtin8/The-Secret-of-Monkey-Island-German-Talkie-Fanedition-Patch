# Den Statusring einordnen

Der Statusring gibt dir einen schnellen Eindruck; den genauen Zustand nennt der Text daneben.

Ein bewegter Ring zeigt, dass der Patch arbeitet. Meldet er eine Warnung oder einen Fehler, lies die Einzelheiten in der Konsole nach. Auch wenn die Ringfarbe später wieder neutral erscheint, bleibt eine gespeicherte Warnung offen.

Steht dort „Bereit“, wartet der Patch auf deine nächste Aktion. Klicke die angebotene Taste, sobald du mit dem nächsten Arbeitsschritt beginnen möchtest.

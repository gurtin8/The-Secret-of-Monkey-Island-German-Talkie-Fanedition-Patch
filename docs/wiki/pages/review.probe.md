# Eine übernommene Probe weiterverwenden

Eine passende Probe muss beim nächsten Verarbeitungslauf nicht nochmals erzeugt werden.

Hast du bereits eine Vorschau übernommen, kann der Patch diese Aufnahme im nächsten Lauf wiederverwenden. Der Hinweis am Dialog sagt dir, ob die angenommene Probe noch zu den aktuellen Einstellungen passt. Änderst du etwa den Text oder den [Rendermodus](review.backend.md), kann eine neue Aufnahme nötig werden.

Dafür musst du nichts eigens einschalten: Beim [Verarbeiten](review.batch.md) nutzt der Patch eine passende freigegebene Probe automatisch weiter. Passt sie nicht mehr, erzeugt der Lauf den Dialog neu.

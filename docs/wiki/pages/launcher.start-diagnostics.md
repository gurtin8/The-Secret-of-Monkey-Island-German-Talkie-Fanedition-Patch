# Das Startprotokoll finden

Das Startprotokoll hilft, wenn du die normale Oberfläche gar nicht erreichst.

Wähle im Patchmenü „Startprotokoll im Finder zeigen“, wenn der Patch nicht startet oder die Oberfläche leer bleibt. Dieses Protokoll ergänzt den Konsolenexport, den du während der eigentlichen Arbeit erstellen kannst.

Wenn du das Problem meldest, notiere außerdem die Patchversion und den letzten sichtbaren Schritt. Zusammen mit dem Protokoll lässt sich damit besser eingrenzen, wo der Start stehen geblieben ist.

# Verzögerungen der Oberfläche untersuchen

Die UI-Diagnose hilft, stockende Bedienung während einer Vorschau einzugrenzen.

Reagieren Schaltflächen oder Audioplayer während einer Vorschau auffällig spät, kann die UI-Diagnose helfen. UI meint hier die Bedienoberfläche. Beim Start einer Vorschau erfasst der Patch automatisch deren Laufzeiten und Zähler. Nach dem Abschluss läuft die Aufzeichnung kurz weiter, damit auch verspätete Reaktionen erfasst werden.

Dafür musst du keine weitere Aufnahme erzeugen. Ist dagegen der Sprachauftrag selbst fehlgeschlagen, lies zuerst die Meldung am Dialog oder im [Auftragsstatus](review.status.md). Sie nennt den Ausgangspunkt für die weitere Suche.

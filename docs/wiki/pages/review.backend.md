# Den Rendermodus für einen Dialog wählen

Der Rendermodus legt fest, welche Hardware die Sprache erzeugt.

Im Feld „Rendermodus“ wählst du, welche Hardware diesen Dialog erzeugt. GPU steht für den Grafikprozessor; ANE ist Apples Neural Engine für KI-Berechnungen. Mit „Stapel“ übernimmst du die gemeinsame Wahl für den Verarbeitungslauf. Wählst du am Dialog eine eigene Rechenmethode, hat sie Vorrang.

Ein Wechsel kann Tempo, Aussprache und Betonung verändern. Höre deshalb eine [Vorschau](review.audition.md) an, bevor du dich entscheidest. Wenn du gerade eine Textkorrektur oder den Stimmanker vergleichst, lass den Rendermodus zunächst gleich. Die [Rendermodi](launcher.render-mode.md) erklären die Wahl für einen ganzen Lauf; bei [geteilten Rezepten](review.recipe.md) hilft diese Angabe anderen, dein Ergebnis einzuordnen.

CPU verwendet den Hauptprozessor und ist experimentell und ungetestet. Möchtest du sie ausprobieren, bestätige diese Wahl für eine Einzelvorschau direkt am Dialog. Für [mehrere ausgewählte Dialoge](review.batch.md) steht die Bestätigung im Stapelbereich.
